## Step 0 — Location confirmation
A z15 satellite probe at the roster point lands inside the Georgia Ports
Authority (GPA) Colonel's Island Terminal at the Port of Brunswick. Web research
(GPA facilities page, glovisusa.com locations, Automotive Logistics) confirms
Colonel's Island is a ~1,700-acre roll-on/roll-off auto terminal with multiple
on-terminal vehicle processors; Glovis America operates as one of those
processors and Brunswick is the nation's busiest RoRo port. The on-terminal
processors share the secured terminal's gate, fence line and storage, so the
audit treats the GPA secured terminal as the facility. Center placed on the
terminal core at 31.1270, -81.5390.

## Gate / guard-shack / dock determinations
- **Truck gate:** TRUE. The terminal is a fully secured GPA port facility
  (TWIC-controlled). All vehicular traffic funnels across one 4-lane divided
  causeway and through a controlled main gate complex before reaching storage
  and processing.
- **Guard shack:** TRUE (medium confidence). A GPA RoRo port terminal of this
  class runs a staffed main gate; small gate-area structures are visible.
  Precise booth identification is flagged uncertain.
- **Backup-sensitive:** TRUE — the entire terminal is served by a single causeway
  with no alternate route; any gate queue would back up along the causeway.
- **Multi-step:** TRUE (best estimate, flagged uncertain) — secured port
  terminals typically run a port gate plus internal processor/yard checkpoints;
  marked truck-staging grids inside the terminal support this.
- **Dock doors:** NONE — a RoRo auto terminal has no loading docks; vehicles roll
  on/off ships and move by drive-away and rail.

## Final confidence
**Medium.** The facility identity, port/RoRo type, rail service, the single-
causeway chokepoint geometry, the controlled secured gate, and the vast vehicle
marshaling are all clearly established. Exact guard-booth identification, lane

sequence could not be positively confirmed from imagery (the gate complex is set
deep inside a secured port with no interior Street View) and are flagged as
uncertain.
