# Performance Food Group — FOV Verification Rejections

FOV scrub run 2026-06-18 (agent, real web research). 30 sites checked: 29 confirmed, 0 probable, 1 rejected.

PFG is a large, stable public company (NYSE: PFGC). No GM-style restructuring, so the bankruptcy-era check is not applicable (`checkedBankruptcyEra: false` on every site). The Cheney Brothers acquisition (closed Oct 2024) carried an FTC-required divestiture, but the divested DCs were in Cheney's own Southeast footprint (FL/NC) and none of the 30 audited sites surfaced on the divestiture list. The legacy Performance Foodservice broadline DCs all remain live on PFG's own location locator. No closures, sales, or WARN shutdowns were found for any operating site.

## Rejected

- **Cheney Brothers - Florence SC (new cold DC)** (Florence, SC — 2491 Florence Harllee Blvd, 29506) — REJECTED: GREENFIELD / UNDER CONSTRUCTION. Existing audit imagery (Feb-2024 Street View + latest Maxar satellite) shows bare graded earth, silt fencing, and construction equipment — no building, docks, gate, or trailers. PFG (Cheney Brothers brand) announced a $42.5M expansion with 85 jobs in March 2026; the facility first broke ground in 2023 and is still being built out. A current-operations audit excludes under-construction sites. This is a real PFG/Cheney project (not divested, not a competitor), so it is a legitimate future re-pin once the building is operational.
